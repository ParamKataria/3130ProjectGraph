# 3130ProjectGraph

Interactive knowledge graph of the CSCI 3130 Group03 marketplace codebase (Django + DRF backend, React + Vite frontend, GitLab CI), generated with Understand-Anything.

Live site: https://paramkataria.github.io/3130ProjectGraph/

- `knowledge-graph.json` — the graph data (781 nodes, 2191 edges, 10 layers, 15-step tour)
- `index.html` + `assets/` — static dashboard build (demo mode, no access token needed)
